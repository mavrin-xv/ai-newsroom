# Contributing

Useful contributions, roughly in order:

1. **Real review runs.** A draft where the panel said SHIP and readers found a problem, or said REWRITE and the draft did fine. Send the anonymised draft, the five verdicts and what happened. This is how the editor lanes and the verdict rules get better.
2. **Editor lanes.** A finding the five editors keep missing, with two drafts that show it. Propose the change to `skills/newsroom-review/references/editors.md`, not a sixth editor.
3. **Lint false positives.** A sentence that `claims_scan.py` or `structure_lint.py` flags wrongly, with the line and the profile that produced it.
4. **Formats.** A format block (words, `h2_max`, `requires`) that works for a kind of article this pack does not cover, with one example draft on an invented company.
5. **Platform drift.** X article rules, title or description limits that changed. Update the fact with the source and the date checked.
6. **Platform reports.** macOS and Linux runs of the checks in [AGENTS.md](AGENTS.md).

Before a pull request, run the checks in [AGENTS.md](AGENTS.md). Keep examples on Northwind Ledger and other invented names, with links to example.org only.

No tracking, no paid services, and no script that publishes anything.
